# Attribution

Browser Zombies is built on third-party models. The code in this repository
is MIT; the models are not, and none of them are redistributed here. They are
fetched from the running site by `fetch-assets.sh`, which is why `models/`,
`fbx/` and `tex/` are gitignored.
